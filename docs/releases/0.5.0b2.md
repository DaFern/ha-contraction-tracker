# 0.5.0b2 — public beta prerelease

## Changes since beta 1

- Idle recording sessions close after 60 minutes since the last completed
  contraction. The retained phone notification can start a fresh session without
  carrying an interval across the gap. Active timers are never automatically
  stopped or assigned an invented end time.
- Movement-reminder opt-in is remembered across recording sessions; explicit Off
  stays Off. Existing Off remains Off until enabled once after upgrade. Reminders
  only concern logged movement and are not a fetal-movement monitor.
- Active timers over two minutes show a banner and, when a phone is configured,
  make one persisted warning attempt. Fractional-start scheduling is corrected.
  If a contraction is still continuing, contact maternity urgently; do not wait
  for a phone warning. Stop/correct a timer left running after it ended.
- Warning tags are isolated per contraction. Active updates no longer enqueue
  premature warning clears; cleanup requires the matching completed record.
  Delayed old cleanup cannot erase a later contraction's warning. Legacy Stop
  authorization and current-token protection remain intact.
- Native measurements, binary diagnostics and verified Activity events support
  automations while preserving the existing Session sensor. Three starter
  blueprints are optional; no household automation is created or enabled.
- Icon-only header controls, centred title and an optional support footer using
  a plain external link, without an embedded payment widget or tracking.

## Install or upgrade

Requires Home Assistant **2026.11 or later** and connectivity to HA. Back up HA
and any records you need before upgrading. Extract the ZIP and copy only
`custom_components/contraction_tracker` into HA's `custom_components` directory,
then **restart Home Assistant** and reload the browser if assets are cached.
Do not remove the existing integration entry to upgrade: removing it deletes
that entry's tracker store. Existing records and original/correction provenance
are retained; Stop/movement controls keep their revision protections.

For a new installation, add Contraction Tracker through Devices & services.
No manually registered frontend resource is required. Phone notifications and
public lock-screen disclosure are optional. Read the README and privacy/data
lifecycle disclosures; this is household-shared data, not a private medical chart.

This logging aid does not determine labour stage, dilation, fetal wellbeing or
when birth will occur, and does not replace advice from your maternity team.
For reduced, stopped or changed baby movements, contact maternity immediately;
do not wait for the optional logging reminder.
